# AWS Student Builder Challenge Submission Guide

**Challenge:** AWS Student Builder Challenge: Build Your Tech Superpower
**Deadline:** November 6, 2026 at 11:59 PM PST
**Portal:** AWS Builder Center ("Your project" tab)

---

## 1. Judging Rubric Alignment

Every submission is evaluated against 4 weighted criteria:

1. **Creativity and Memorability (30%):**
   - *Requirement:* A distinctive creative feature that reflects you, is interactive, works, and has a visible hint without impeding navigation.
   - *Implementation:* The **V4 Superpower Engine Console** with 4 interactive cylinders: Aegis-2B AI guardrail bench, Green FinOps & poverty relief calculator, CS Peer Tutor challenge, and Kaizen rev motto generator with live tachometer.
   - *Visible Hint:* Explicit `[ Superpower Engine (Hint!) ]` button in the top navigation bar.

2. **Working AWS Implementation (25%):**
   - *Requirement:* Hosted on AWS, loads reliably throughout judging, core links work, AWS usage documented.
   - *Implementation:* AWS Amplify Hosting + Amazon CloudFront CDN + Amazon S3 with continuous CI/CD from GitHub.

3. **Communication Quality (25%):**
   - *Requirement:* Clear write-up, screenshots of portfolio and AWS setup, documented AWS services, challenges and learnings.
   - *Implementation:* Structured project submission covering architecture, FinOps philosophy, healthcare IT lessons, and peer tutoring.

4. **Portfolio Completeness and Usability (20%):**
   - *Requirement:* Three core sections (About Me, Skills/Tech Superpowers, Projects/Achievements), mobile and desktop responsive.
   - *Implementation:* Full 3-section layout + clean navigation + responsive Tailwind layout.

## 3. Builder Center Project Write-up Template

Copy and tailor this template when entering your project in the challenge portal:

### Project Title
**Mohamed Makhlouf - Cloud DevSecOps & AI Security Superpower Portfolio**

### Elevator Pitch
A high-performance personal portfolio website deployed globally on AWS Amplify Hosting, combining mechanical engine precision with Japanese Sakura aesthetics. Features the interactive V4 Superpower Engine console, showcasing sub-115ms AI security guardrails, green cloud FinOps, and UTM peer mentorship.

### The Creative Feature & Visible Hint
The creative feature is **The Superpower Engine (V4 Console)**, discovered via a visible `[ Superpower Engine ]` button with a pulsing hint badge in the top navigation.
The engine console features 4 interactive cylinders:
- **Cylinder 1 (AI Guardrail Bench):** Allows reviewers to test prompt injections and safe queries against an interactive simulation of Aegis-2B (regex trie + 2B SLM verifier) reporting sub-115ms latency.
- **Cylinder 2 (Green Cloud & Poverty Relief):** Computes energy and cost savings from serverless scale-to-zero architectures, translating saved cloud dollars into community meals or student kits.
- **Cylinder 3 (UTM Peer Tutor Quiz):** Interactive questions testing AWS IAM policy evaluation and low-latency SLM choices with tutor notes from my sessions at UTM.
- **Cylinder 4 (Kaizen Rev & Sakura Fortunes):** An interactive mechanical rev button pushing the tachometer to 8,800 RPM, triggering a petal burst, and dispensing engineering build lessons.

### AWS Services Used
- **AWS Amplify Hosting:** Automated CI/CD pipeline building Vite/React from GitHub on every push.
- **Amazon CloudFront:** Global edge distribution for low-latency HTTPS delivery.
- **Amazon S3:** Encrypted storage of production build artifacts.
- **AWS Lambda & Amazon Bedrock (Contextual Architecture):** Architecture reference for the featured Aegis-2B and A2 Remediation Engine projects.

### Challenges Hit & Key Learnings
- **Challenge:** Creating an interactive multi-station dashboard without cluttering standard portfolio navigation.
- **Resolution:** Decoupled the engine into a modal overlay accessible via a visible hint button, allowing reviewers to explore the telemetry at their own pace without obstructing reading flow.
- **Key Learning:** Precision in UI and infrastructure follows the same principles as mechanical engines: eliminating friction, optimizing latency budgets, and automating continuous delivery.
