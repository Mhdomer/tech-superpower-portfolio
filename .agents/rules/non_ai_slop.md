Whenever working in this codebase, the agent MUST adhere to these strict rules. Any output violating these guidelines is considered broken and must be rewritten.

## 1. Zero Corporate Fluff & Robotic AI Language

Never use standard AI marketing jargon or synthetic enthusiasm.

### Banned Phrases & Words
- "In today's fast-paced cloud landscape..."
- "A testament to..."
- "I am thrilled to announce / share..."
- "Let's dive in / delve into..."
- "Game changer / cutting edge / revolutionary"
- "Seamless integration / seamless user experience"
- "Harness the power of..."
- "Crucial aspect / tapestry / multifaceted"
- "Beacon of hope / transformative journey"

### Required Voice

- Write from the perspective of an engineer in the trenches: working on Linux systems, tuning kernel flags, fighting latency bottlenecks, testing IAM policies, and debugging real crashes.
- Be technical, grounded, and concise. State the fact, cite the benchmark or command, and move on.

## 2. Zero AI Slop in UI & Design

Generic "AI-built" portfolios share distinct ugly patterns. Avoid all of them:
- **No Purpled-Out Gradient Vomit:** Do not paint every heading in a 3-stop generic purple-pink-cyan gradient. Use solid white text with selective, crisp sakura pink (`#f472b6`) or engine cyan (`#38bdf8`) accents where contrast demands attention.
- **No Generic Card Grids With Floating Emojis:** Do not place large random emojis (`🚀`, `💡`, `🔥`, `⚡`) as card headers. Use clean Lucide icons or custom SVGs in structured badges.
- **No Fake Metrics:** Every stat displayed (e.g. `115ms p99`, `6/6 tests passing`, `99.98% uptime`) must be grounded in actual project benchmarks (Aegis-2B pytest suite, Al-Ameen clinic uptime, UTM lab results). Never write "10x productivity" or "1000% scalable".
- **No Unused Dummy Buttons:** Every interactive element (buttons, tabs, sliders, toggles) must perform real state changes or navigate to valid destinations. No dead "Learn More" links pointing to `#`.

## 4. Strictly Zero Em Dashes

- **NEVER** use em dashes (`—`, `–`, or `--` used as a punctuation dash).
- Use commas, periods, colons, parentheses, or clean bullet points (`•`, `*`) instead.
- This rule applies to all markdown documentation, UI copy, code comments, and git commit messages.
